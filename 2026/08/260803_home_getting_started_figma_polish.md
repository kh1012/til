# 조각으로 쪼갠 다음에야 시안을 맞출 수 있었다

> home-getting-started는 인사 헤딩과 첫 그룹 생성 유도, 퀵스타트가 한 컴포넌트에 뭉쳐 있었다. 오늘 이걸 세 조각으로 쪼개고 퀵스타트에서 추천 작업 목록을 한 번 더 떼어낸 뒤, Figma 시안 노드를 하나씩 열어 아이콘 글리프부터 라운딩·간격·폰트 무게까지 맞췄다. 스무 번 넘게 고쳤는데, 쪼개 두지 않았으면 한 번 고칠 때마다 전체가 흔들렸을 것이다.

## 배경

home-getting-started는 대시보드 첫 화면을 통째로 담당하는 컴포넌트였다. 인사말, 첫 프로젝트 그룹을 만들라는 유도 카드, 퀵스타트 카드가 한 파일 안에 있었고 셋이 상태를 공유하지도 않으면서 함께 붙어 있었다.

이 상태에서 Figma 시안을 반영하려면 문제가 생긴다. 시안은 카드 단위로 그려져 있는데 코드는 화면 단위라 대조가 안 맞고, 한 조각을 고칠 때마다 나머지 둘까지 같은 파일에서 흔들린다. 갤러리에서 조각 하나만 따로 보거나 갈아끼울 방법도 없다.

그리고 이날 하루 종일 이 컴포넌트들을 스무 번 넘게 고치게 되는데, 그 반복이 가능했던 게 쪼개 둔 덕분이었다.

## 핵심 내용

### 개별 작업 기록 (시간순)

- home-getting-started를 3개 조각 컴포넌트로 분리
  - 인사 헤딩, 첫 그룹 생성 유도, 퀵스타트를 각각 staging 컴포넌트로 떼어내고 home-getting-started에는 세 조각을 조립하는 자리만 남겼다. 세 조각은 상태를 공유하지 않고 각자 자기 슬롯만 그리므로 따로 쓰거나 갈아끼울 수 있다.
  - 기존 타입은 퀵스타트 쪽 타입의 재수출 별칭으로 남겨 import 경로를 그대로 뒀다. 레지스트리의 `composedOf`를 primitive 나열에서 조각 3개로 바꾸고, 새 엔트리와 갤러리 썸네일을 등록했다.

- CTA 폰트 한 치수 확대
  - '첫 프로젝트 그룹 만들기' 버튼 폰트를 한 단계 올리고 사이드카 히스토리에 수정 이벤트를 남겼다.

- 퀵스타트에서 추천 작업 목록 조각 분리
  - '추천 작업' 라벨과 반복 행 목록을 별도 엔트리로 승격하고, 퀵스타트는 카드 셸에 조각을 조립하는 형태로 재작성했다. 공개 props와 export 이름은 유지하고 행 타입은 alias로 보존했다.
  - 이후 오늘 하루의 시안 반영 작업 대부분이 이 조각 하나에 집중된다. 떼어내길 잘한 자리다.

- 추천 작업 행 붙이고 목록 양 끝 pill 라운딩
  - 행 사이를 붙이고 목록 전체의 양 끝을 pill로 둥글렸다.

- 퀵스타트 카드에 Figma 시안 반영
  - 시안 노드를 열어 카드 그라데이션, 장식 원, 헤더 타이포를 맞췄다.

- 그룹 유도 카드 아이콘·타이포를 Figma 시안에 맞춤
  - 아이콘 글리프를 Layers에서 FileStack으로 바꿨다. 시안 벡터가 lucide의 file-stack과 일치했다.
  - 아이콘 박스를 accent 10% 배경에 accent 스트로크로, 제목을 한 단계 작게 하고 extrabold로, 설명을 더 작게 하고 줄 간격을 넉넉하게, 설명과 버튼 사이 간격을 시안의 20px에 맞춰 넓혔다. 버튼 폰트 크기는 그대로 뒀다.

- 애니메이션 계약 감사 스냅샷 갱신
  - 새 컴포넌트 엔트리가 늘어 감사 대상 카운트가 58에서 59가 됐다. 인증된 스냅샷과 목록을 실제 값으로 갱신했다. (같은 이유로 앞서 50에서 58로 올린 갱신도 있었다.)

- 추천 작업 목록 라운딩을 세 번 조정
  - pill(`rounded-full`)에서 `rounded-lg`로, 다시 `rounded-xl`로, 마지막에 `rounded-2xl`로 옮겨갔다.
  - 마지막 단계에서 radius 스케일에 2xl(16px)을 정식으로 추가했다. 토큰 정의, CSS 변수, 테마 SSOT, 가이드 하드룰까지 네 곳을 함께 채웠다. 기존에 미승격 상태로 남아 있던 토큰 제안을 이번 요청으로 승격 처리한 것이다.

- 그룹 유도 카드 여백과 높이를 반복 조정
  - CTA 버튼 세로 여백을 넓히고, 섹션 높이를 284px 근사치인 h-72로 지정했다가 350px 근사치인 h-80으로 다시 올리면서 내부 콘텐츠를 수직 중앙 정렬했다.
  - 다크 테마에서 CTA 버튼에 뿌옇게 끼던 그림자도 제거했다.

- 추천 작업 아이콘을 Figma 디자인에 맞춰 두 번 교체
  - 먼저 시안 노드 셋을 대조해 스택 모양은 Database로, 파일 겹침은 Files로 교체했다(기존 GitCompare와 Boxes 대체). 방패에 체크 모양은 이미 쓰던 ShieldCheck와 일치해 유지했다. 데모, 스토리, 갤러리 썸네일 세 곳을 동기화했다.
  - 나중에 같은 시안 노드의 SVG를 lucide 아이콘과 다시 대조했더니, 3-path 구조(닫힌 다이아몬드에 열린 쉐브론 2개)가 정확히 일치하는 건 Layers였다. 목업 아이콘 셋을 Layers로 교체했다. **모양이 비슷한 것과 path 구조가 일치하는 것은 다르고, 후자만 확실한 근거다.**

- 추천 작업 행 다듬기
  - 각 행 우측 '추가' 버튼에 pill 라운딩을 적용했다(sm 사이즈 기본 radius를 override).
  - 아이콘과 텍스트 사이 간격을 넓히고, 제목은 extrabold에 전경색, 설명은 normal에 muted 색으로 대비를 명시했다.
  - 아이콘 배지를 사각형에서 28px 원형 배지에 accent 9% 틴트 배경으로 교체했다. 아이콘 글리프 자체는 별도 논의로 남겼다.
  - 마지막으로 배지를 고정 28px 대신 `aspect-square`에 `self-stretch`로 바꿔, 우측 제목·설명 텍스트 블록의 위아래 끝에 높이를 맞추면서 원형을 유지하게 했다.

- 표시명·설명 정리
  - home-getting-started와 갈라낸 조각들(greeting, group-prompt, quick-start)의 표시명과 설명을 여러 차례 수정했다. 오늘 하네스에 새로 붙인 표시명 기능의 첫 실사용이기도 했다.

## 정리

오늘 이 컴포넌트에 손댄 횟수를 세어 보면 스무 번이 넘는다. 라운딩만 네 단계를 옮겨 다녔고 아이콘 글리프는 두 번 갈아치웠다. 이런 반복이 견딜 만했던 건 **먼저 쪼개 뒀기 때문**이다. 인사·그룹 유도·퀵스타트로 나누고 퀵스타트에서 추천 작업 목록을 한 번 더 떼어내고 나니, 이후 변경의 대부분이 조각 하나 안에서 끝났다. 쪼개기 전이었다면 라운딩 하나 고칠 때마다 화면 전체가 diff에 들어왔을 것이다.

쪼갤 때 지킨 건 두 가지다. 공개 props와 export 이름을 그대로 두고 기존 타입은 재수출 별칭으로 남겨 import 경로를 안 깨뜨렸고, 레지스트리 `composedOf`를 primitive 나열에서 조각 3개로 바꿔 구성 관계가 실제 구조를 반영하게 했다. 겉에서 보면 아무것도 안 바뀌었지만 안에서 갈아끼울 수 있게 된 상태다.

**Figma 시안 대조에서 배운 건 "비슷하다"와 "일치한다"의 차이**다. 아이콘을 처음 교체할 때는 시안 모양을 보고 Database와 Files를 골랐는데, 나중에 같은 노드의 SVG를 lucide 아이콘의 path 구조와 직접 대조하니 답은 Layers였다. 닫힌 다이아몬드 하나에 열린 쉐브론 둘이라는 3-path 구조가 정확히 맞았다. 눈으로 비슷한 걸 고르면 몇 번을 다시 고치게 되고, 벡터 구조를 대조하면 한 번에 끝난다.

라운딩을 네 번 옮겨 다닌 끝에 **radius 2xl을 토큰 스케일에 정식으로 들인 것**도 오늘의 수확이다. 값 하나가 필요할 때 그 자리에 임의 값을 쓰는 것과 스케일에 한 칸을 더하는 것은 다르다. 후자는 토큰 정의, CSS 변수, 테마 SSOT, 가이드 하드룰 네 곳을 함께 채워야 하지만, 그 다음부터는 같은 값이 필요한 모든 자리가 같은 이름으로 부른다. 마침 이 값은 이전에 토큰 제안으로 올라와 있다가 승격되지 않은 채 남아 있던 것이라, 실제 필요가 생긴 이번 요청으로 승격 처리했다. 제안은 쌓아 두고 실제 수요가 왔을 때 올리는 게 맞는 순서였다.
